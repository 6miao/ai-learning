# 计划生成器 · 一体式（Plan Generator）

一个**纯前端、单文件、一体式**的计划制定工具。

流程：**选计划类型 → 填需求问卷 → 看反馈分析 → 一键生成可执行的每日计划（可导出 Word）**。

## 特点
- **零后端、零依赖**：双击 `index.html` 即可离线使用，发给别人也能直接用。
- **通用模板**：内置 考研 / 考公·编制 / 求职·实习 / 技能自学 / 项目·副业 / 习惯养成 / 其他（自由描述）。选「其他」并写下你的目标，系统会随机应变自动生成专属需求题。
- **角色化追问**：考研/考证＝老师（导师）口吻，求职/考公＝HR（面试官）口吻，技能/习惯/项目＝教练（陪练）口吻。
- **AI 替你填整套（可选）**：填自己的大模型密钥后，点一下 AI 就把「需求问卷答案 + 反馈分析 + 每周计划」全部填好；没有资料它会替你创造合理资料。
- **导出 Word**：计划表阶段可一键导出 Word 模板（五列排版）。

## 怎么用
1. 直接双击 `index.html`；或部署到任意静态托管（GitHub Pages / Vercel / Netlify / 任意服务器）。
2. 第一步选「这是什么计划」；第二步按类型填需求问卷（自己填，或让 AI 填）。
3. 生成反馈表 → 提交生成计划 → 点「生成 Word（Word模板1）」导出。

## 关于「AI 替你填整套」
- 展开「🤖 AI 替你填整套」，填入你**自己的**大模型密钥（兼容 OpenAI / DeepSeek / Moonshot / 通义 / 智谱 等的 `/chat/completions` 接口）。
- 密钥只存在你本机浏览器，**不经任何第三方**。
- 不想配密钥也能用：直接跟你的 AI 助手说「帮我出一份 XX 计划的需求问卷」，把对方给的 JSON 粘到「📋 免密钥导入」即可。

## 部署成公开链接（GitHub Pages）
把本目录推到 GitHub 仓库后：仓库 **Settings → Pages → Source 选 `master` 分支、`/（root）` → Save**，稍等一两分钟即可获得公开网址，别人点开就能用。
