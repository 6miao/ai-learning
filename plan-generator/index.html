第一步 · 这是什么计划？（先确定计划类型）

这一页只做一件事：选清楚"这是什么计划"。选好之后，下一页系统会自动用最贴合的角色（考研/考证=老师，求职/考公=HR，技能/习惯/项目=教练）给你出对应的专属详细需求问卷；选"其他（自由描述）"就写下你的目标，系统随机应变自动生成专属题。确定后点「下一步 → 填详细需求」。

第二步 · 详细需求问卷（按你选的「计划类型」定制）

这一页的问题是根据你上一页选的类型定制的：通用基础题 + 该类型专属题。单选 / 多选直接勾，填空 / 文本域按实填；每题下方都有"本题补充"框，选项里没有的自己写。想让 AI（WorkBuddy）帮你出专属题：把文件发我预填，或粘我给的 JSON 到下方「📋 免密钥导入」。填完点「生成反馈表 →」。
选好计划类型后，系统会自动用最贴合的角色（老师 / HR / 教练）来问你细节。
🤖 AI 替你填整套（需自己的大模型密钥 · 联网）
这是"不用自己填"的开关：点一下，AI 就按你选的计划类型 + 具体目标 + 对应角色口吻，直接替你把需求问卷的答案、反馈分析、每周计划全部填好（没有资料 AI 还会替你创造具体资料）。生成后你只复核、改想改的。密钥只存在你本机浏览器，不经任何第三方。支持 OpenAI / DeepSeek / Moonshot / 通义 / 智谱 等兼容 /chat/completions 的接口。
📋 免密钥导入（个人使用推荐 · 直接把 WorkBuddy 给你的题粘进来）
你自己用这个工具时，不用填任何密钥：直接跟我说"帮我出一份 XX 计划的需求问卷"，我把问题以 JSON 发你，粘到下面点「📥 导入」即可（完全离线、不发任何网络请求）。也可以把本文件发我，我直接帮你把题写进文件，你打开就预填好了。
